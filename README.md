# Comillas PE&VC Club — Official Website

Official website and knowledge platform for the **Comillas Private Equity & Venture Capital Club** at Universidad Pontificia Comillas (ICAI · ICADE), Madrid.

---

## Architecture & Views

- **Home:** Hero, Who We Are & What We Do, Key Impact Metrics, and Industry Partners.
- **Deal Analyst Program:** Scrollytelling overview, methodology, syllabus verticals, and application process.
- **Resources Hub:**
  - **Academic Courses:** Private Markets 101 & Venture Capital 201
  - **Analyst Insights & Deal Briefs:** Cohort transaction memos
  - **Industry & Sector Reports:** Institutional reports from Bain, McKinsey, BCG, PwC, CB Insights
  - **Specialized External Reports:** 16 technical primers and playbooks
  - **Proprietary Tools:** CAIA Study App & Debt Structure Simulator
- **Contact:** Email, LinkedIn, Instagram, and official WhatsApp Community.
- **Legal Notice & Disclaimers:** Independence, Educational Use, and Financial Disclaimers.

## Deployment & Local Run

### Local Preview
You can run a local HTTP server with Python:
```bash
python3 -m http.server 4000
```
Then open `http://localhost:4000` in your browser.

### Hosting on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. The website will be live at `https://<your-username>.github.io/<repo-name>/`.
